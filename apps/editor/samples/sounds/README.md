# Sound library

The 400 sounds the editor ships with (Assets › Sounds › Sound library), from the "400 Sounds Pack", supplied
by the project owner. Folders are the pack's own. The originals were WAV; they are kept here as
Ogg Vorbis (quality 4) to keep the editor small. Using a sound copies it into a project's `assets/sounds`.

Licence (from the pack): "You may use these game assets for ANY and ALL uses including commercial use, with or
without giving credit, except that you may not sell or redistribute the unaltered assets as your own game assets."
Shipping them inside the engine is allowed as long as they aren't sold separately.
